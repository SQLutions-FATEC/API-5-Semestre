
## DoD (Definition of Done)

- Testes para as features escritos
- Passou nos testes do projeto
- Passou no code review
- Confirmado com o PO
- Codigo mergeado na branch principal

## DoR (Definition of Ready)

- User story descrita
- Valor de negocio explicitado
- Criterios de aceite escritos
- Wireframe basico da pagina disponivel
- Regras de validação de campos definidas
